ROAD RUSH - Browser Car Driving Game

1. Extract this ZIP file.
2. Open the road_rush_car_game folder.
3. Double-click index.html and open it with Google Chrome.
4. Press START GAME.

Controls:
- Left / Right buttons: steering
- BRAKE button: slow down
- GO! button: accelerate
- Keyboard: arrow keys (or A/D and W/S)

The driver is visible inside your red car. This is a simple arcade-style browser game and requires no installation.
